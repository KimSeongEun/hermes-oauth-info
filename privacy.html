Google API 연동 테스트 개인정보처리방침

적용일: 2026-10-16

목적과 범위

이 정책은 비공개 사용 목적의 Google API 연동 테스트 앱과 해당 앱의 정적 안내 페이지에 적용됩니다. 앱은 일반 사용자 모집을 목적으로 하지 않으며, Google의 공식 서비스가 아닙니다.

접근할 수 있는 데이터

사용자가 동의한 OAuth 권한과 실제 요청에 따라 Gmail 메시지와 메타데이터, 캘린더 일정, Drive 파일과 메타데이터, Sheets 셀 내용, Docs 내용 및 연락처 정보에 접근할 수 있습니다. 실제 요청 권한은 Google OAuth 동의 화면에서 확인할 수 있습니다. 권한 동의가 모든 API의 활성화나 기능 성공을 뜻하지는 않습니다.

사용 목적

인증 및 API 연결 확인, 사용자가 요청한 데이터 조회·검색·요약·분석과 승인된 메일 발송·일정 변경·문서 편집 등을 위해 데이터를 처리합니다. 발송·변경·공유·삭제는 사용자의 구체적인 요청과 승인을 전제로 합니다.

자동화된 처리와 외부 전달

요청 수행에 필요한 일부 데이터는 자동화된 데이터 처리 또는 메시지 전달을 위한 외부 서비스로 전송될 수 있습니다. 외부 서비스는 입력 데이터와 처리 결과를 해당 서비스 정책 및 계정 설정에 따라 처리하거나 보관할 수 있습니다. 모든 데이터가 실행 기기 내부에만 머무는 것은 아니며, 외부 서비스의 학습 이용 여부나 보관 기간에 대해 확인되지 않은 보장을 하지 않습니다.

저장과 보관

OAuth 인증정보는 앱 실행 환경에 보관되며 공개 저장소와 안내 페이지에 게시하지 않습니다. 처리한 데이터나 요약 일부는 대화 기록·작업 파일·로그에 포함될 수 있습니다. 자동 삭제 기간은 현재 확정하지 않았으며, 삭제가 필요하면 운영자가 관련 기록과 파일을 확인해 처리합니다. 외부 서비스에 남은 기록은 해당 서비스 정책과 관리 설정에 따릅니다.

제한된 사용

Google 데이터는 사용자가 요청한 연동 기능을 위해 사용하며, 운영자가 판매하거나 광고 목적으로 사용하지 않습니다. Google API를 통해 받은 정보의 사용 및 다른 앱으로의 이전은 Google API Services User Data Policy의 Limited Use 요구사항을 따르는 것을 운영 원칙으로 합니다. 처리 방식이 이 원칙에 어긋나는 경우 해당 작업을 중단하고 설정 및 정책을 수정해야 합니다.

권한 철회와 삭제

사용자는 Google 계정의 서드 파티 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 권한 철회가 이미 저장된 대화·파일·로그 및 외부 서비스 기록을 자동 삭제하지는 않습니다. 필요한 자료는 별도로 확인하여 삭제해야 합니다.

안내 페이지

공개 안내 페이지와 저장소에는 소개 및 정책 문안만 게시하며 Google 개인자료나 인증정보는 포함하지 않습니다. 안내 페이지에는 로그인·입력 양식·추적 스크립트가 없습니다. 호스팅 과정에서 처리되는 방문 정보에는 GitHub 개인정보처리방침이 적용됩니다.

문의와 변경

운영자는 GitHub 프로필에서 확인할 수 있습니다. 데이터 처리 방식이 변경되면 이 정책을 업데이트합니다.
