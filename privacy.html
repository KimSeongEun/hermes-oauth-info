Hermes Personal Assistant 개인정보처리방침

적용일: 2026-10-16 (Asia/Seoul)

목적과 범위

이 정책은 운영자 개인용 Hermes 비서의 Google API 데이터 처리 및 해당 앱의 정적 안내 사이트에 적용됩니다. 앱은 별도의 일반 사용자 모집을 목적으로 하지 않습니다. 이 개인용 설정은 Google 또는 Nous Research의 공식 서비스가 아닙니다.

접근할 수 있는 Google 데이터

동의한 OAuth 권한과 실제 사용 요청에 따라 Gmail 메시지와 메타데이터, 캘린더 일정, Drive 파일과 메타데이터, Sheets 셀 내용, Docs 내용, 연락처 정보에 접근할 수 있습니다. 인증 권한이 있더라도 모든 API가 활성화되거나 모든 기능이 성공하는 것은 아닙니다. OAuth 동의 화면에서 실제 요청 권한을 확인할 수 있습니다.

사용 목적

이메일과 일정 조회·요약, 답장 및 문서 작성 보조, 자료 검색과 분석, 사용자가 승인한 메일 발송·일정 변경·문서 편집 등을 수행하기 위해 데이터를 처리합니다. 이메일·문서 안의 내용을 외부 작업에 대한 별도 실행 승인으로 취급하지 않습니다.

AI 처리와 외부 전달

요청을 처리하는 데 필요한 Google 데이터 일부가 설정된 AI 모델 제공 서비스로 전송될 수 있습니다. 현재 운영에 사용되는 서비스는 Microsoft Foundry 기반 모델 엔드포인트이며, 실제 저장·보관 및 데이터 이용 조건은 해당 계정과 서비스 설정에 따릅니다. Discord로 요청한 경우 사용자의 요청과 결과 메시지는 Discord를 통해 전달되어 해당 서비스에 저장될 수 있습니다. 이 안내는 앱의 모든 데이터가 기기 내부에만 머문다는 약속이 아닙니다. 외부 제공자의 학습 이용 여부나 보관 기간에 대해서는 확인되지 않은 보장을 하지 않습니다.

저장과 보관

OAuth 인증정보는 운영자의 실행 환경에 보관되며 공개 저장소와 이 사이트에 게시하지 않습니다. Google에서 읽은 일부 데이터나 요약은 요청 처리 과정에서 로컬 대화 기록·작업 파일·로그에 포함될 수 있습니다. 별도의 자동 삭제 기간은 현재 확정하지 않았으며, 보관 자료 삭제가 필요하면 운영자가 관련 로컬 기록과 작업 파일을 확인해 처리합니다. Discord와 AI 제공 서비스의 기록은 해당 서비스 정책과 관리 설정에 따릅니다.

제한된 사용과 공개 범위

Google 데이터는 사용자가 요청한 개인 비서 기능을 위해 사용합니다. 앱 운영자는 이를 판매하거나 광고 목적으로 사용하지 않습니다. Google API 데이터 사용 및 다른 앱으로의 이전은 Google API Services User Data Policy의 Limited Use 요구사항을 따르는 것을 운영 원칙으로 합니다. 실제 처리 방식이 이 원칙과 어긋나는 경우 해당 작업을 중단하고 설정 및 정책을 수정해야 합니다. 공개 Pages 사이트와 저장소에는 앱 안내·정책 문안만 게시하며 Google 개인자료·인증정보는 포함하지 않습니다.

권한 철회와 삭제

사용자는 Google 계정의 서드 파티 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 권한 철회는 이미 남은 로컬 대화·파일·로그나 외부 서비스 메시지를 자동 삭제하지 않습니다. 운영자는 필요한 경우 해당 자료를 별도로 삭제해야 합니다.

안내 사이트 호스팅

이 사이트는 GitHub Pages를 사용합니다. 호스팅 서비스가 처리하는 방문 정보에는 GitHub의 개인정보처리방침이 적용됩니다: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . 이 정적 사이트에는 별도의 로그인·입력 양식·추적 스크립트를 추가하지 않습니다.

문의와 변경

운영자는 https://github.com/KimSeongEun 프로필에서 확인할 수 있습니다. 데이터 처리 방식이 변경되면 정책을 업데이트합니다. 상세 문의용 이메일을 공개할지는 별도 확인 후 결정합니다.
