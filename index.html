Google API 연동 테스트

Google OAuth 인증과 API 연동 기능을 확인하기 위한 비공개 사용 목적의 테스트 앱입니다. 승인된 계정과 권한 범위에서 데이터 조회·처리 및 사용자가 요청한 작업을 수행합니다. 일반 사용자 모집을 목적으로 하지 않습니다.

이 페이지는 앱 소개와 개인정보처리방침을 제공하는 정적 안내 페이지입니다. 계정 로그인, 파일 업로드 또는 사용자 입력 기능을 제공하지 않습니다. Google이 제공하거나 보증하는 공식 앱이 아닙니다.

데이터 접근과 사용, 외부 처리 및 권한 철회에 관한 내용은 개인정보처리방침에서 확인할 수 있습니다.
